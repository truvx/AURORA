Medium Severity Findings

Medium

Rate limiting is process-local, not global

web/lib/ai/guard.ts:45
Rationale

The RateLimiter uses an in-memory Map. In a scaled deployment with multiple instances, the rate limit is multiplied by the number of pods, allowing users to bypass the intended 20 req/min limit by hitting different instances.

Remediation: Implement a shared state store (e.g., Redis) for rate limiting to ensure global enforcement across all production instances.

Low Severity Findings

Low

Duplicated queue navigation logic between Web and Android

web/lib/player/coordinator.ts:247
Rationale

The web coordinator implements skipPrevious and skipNext logic that nearly duplicates the Android implementation. Divergence in shuffle or repeat behavior is likely over time.

Remediation: Extract queue navigation logic (stepThrough, shuffledOrderFrom) into a shared domain specification or utility.
Low

Crossfade guard reset relies on position change

android/.../PlayerCoordinator.kt:478
Rationale

The crossfadeFired guard is reset reactively based on event.elapsed < lastElapsedMs. This is fragile if the engine emits an unexpected position event during transition.

Remediation: Explicitly reset crossfadeFired = false inside loadTrack to proactively ensure eligibility for every new track.
Low

YouTube IFrame controls may be overly restrictive

web/lib/player/youtubeAdapter.ts:69
Rationale

The implementation forces controls: 1. While compliant with branding policies, it contradicts the goal of using AURORA's custom "Liquid Glass" controls as the primary interface.

Remediation: Evaluate using controls: 0 when the AURORA transport is active, provided branding requirements remain satisfied.
Low

Web client currently lacks YouTube playback

web/lib/player/coordinator.ts:247
Observation

The web coordinator returns error messages for YouTube tracks. This is a known state and aligns with the policy against fake playback, but marks a capability gap compared to Android.

Remediation: No immediate fix required; ensure the upcoming YouTube IFrame adapter follows the provider-neutral HtmlAudioAdapter interface.
