# Design references

Third-party brand analyses from [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md/tree/main/design-md), kept for inspiration only.

- `apple-DESIGN.md`: premium restraint, typography, and glass/translucency cues. Adapted to Space Mono (400/700, near-zero tracking) per ADR-015.
- `spotify-DESIGN.md`: dark music-player layout and density.

These files are not the AURORA spec. `docs/AURORA_MASTER_DESIGN_SYSTEM.md` and `docs/DESIGN_TOKENS.md` win on every conflict. Do not copy brand colors, SF Pro, or other proprietary assets (see ADR-002 and ADR-015).
